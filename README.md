SearchCrypt

About the Project

SearchCrypt is a privacy-preserving employee search system developed using Python. It aims to protect employee information using encryption.

Problem

When sensitive employee information is stored and searched, protecting that information from unauthorized access is important.

Proposed Solution

SearchCrypt aims to encrypt employee data and provide a way to search for information while improving privacy.

Technologies Used

- Python
- Flask
- SQLite
- Cryptography (Fernet)

Current Progress

- Created the initial Python application.
- Started implementing encryption using Fernet.
- Tested the encryption functionality.

Future Work

- Complete encrypted data storage.
- Implement secure employee search.
- Add search-history monitoring.
- Explore adaptive privacy protection.

Project Status

Work in progress. The complete system is still under development.
